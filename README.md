## Introducción
El presente proyecto consiste en el análisis y diseño de una plataforma web y móvil para Supermaxi, orientada a facilitar las compras en línea y mejorar la experiencia de los clientes. El sistema contempla el registro de usuarios, la consulta de productos, la realización de pedidos y el análisis del historial de compras para generar promociones personalizadas, siempre respetando el consentimiento de los clientes. Además, se establecen requisitos funcionales y no funcionales, junto con sus respectivos casos de prueba y resultados esperados, considerando aspectos importantes como la usabilidad, la seguridad y la privacidad de los datos personales.
## Requisitos funcionales y no funcionales
|ID|Tipo de requisito|Descripción del requisito|Caso de prueba propuesto|Resultado esperado|
|--|-----------------|-------------------------|------------------------|------------------|
|RF-01|Funcional|El sistema permitirá a los clientes registrarse mediante el ingreso de sus datos personales para acceder a la plataforma.|Ingresar los datos solicitados en el formulario de registro y seleccionar la opción de crear cuenta|El sistema deberá registrar al cliente y mostrar un mensaje de confirmación|
|RF-02|Funcional|El sistema permitirá analizar el historial de compras de los clientes para generar promociones personalizadas|Verificar que el sistema genere promociones personalizadas utilizando el historial de compras de un cliente que haya autorizado expresamente el uso de sus datos.|El sistema deberá mostrar promociones relacionadas con los hábitos de compra del cliente y utilizar sus datos únicamente con su autorización.|
|RF-03|Funcional|El sistema permitirá realizar pedidos y pagos electrónicos|Seleccionar los productos y agregarlos al carrito de compras y confirmar el pedido mediante el proceso de compra|El sistema deberá registrar el pedido y mostrar la confirmación de la compra|
|RNF-01|No funcional|El sistema deberá garantizar la protección de los datos personales de los clientes, evitando el uso no autorizado de su información.|Verificar que los datos personales de los clientes sean utilizados únicamente para los fines que estos hayan aceptado|El sistema deberá proteger los datos personales y evitar que sean utilizados para fines no autorizados por el cliente|
|RNF-02|No funcional|El sistema deberá contar con una interfaz sencilla e intuitiva que facilite a los clientes la navegación y realización de sus compras.|Solicitar a un cliente que navegue por la plataforma, busque un producto y realice una compra por primera vez|El cliente deberá poder usar la plataforma y completar su compra de manera sencilla e intuitiva, sin dificultades|
